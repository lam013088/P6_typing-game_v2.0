# 🎮 六年級速成打字遊戲寶可夢主題版 (GitHub 部署版)

本專案為小學六年級採用寶可夢野生原野隨機遊行抓寶機制，激發學生練習興趣。

---

## 🔒 個人私隱安全承諾 (Zero-PII Compliance)
* **100% 去識別化**：本專案所有檔案、程式碼、排行榜與資料結構中，**完全不包含任何學生真實姓名與個人隱私資料**。
* **僅識別班別與學號**：學生端僅使用「班別（P4A～P4F）」與「座號學號（1～36號）」（如 `P4A 01號`）進行挑戰與榜單展示。
* **真實成績安全隔離**：真實姓名僅保存在教師個人 Google 雲端試算表中；學生端透過 Webhook 提交班級與學號時，由後端自動映射，學生在 GitHub 上無法查看或修改任何同學的真實資訊。

---

## 🚀 GitHub Pages 快速部署指南 (1 分鐘上線)

1. **建立 / 進入 GitHub Repository**：
   * 在 GitHub 上新建一個公開儲存庫（Repository），例如命名為 `p4-typing-game` 或直接使用現有儲存庫。
2. **上傳檔案**：
   * 將本目錄下的 `index.html` 直接上傳（或 Commit）至儲存庫的根目錄（Root）。
3. **啟用 GitHub Pages**：
   * 進入儲存庫的 **「Settings」➔「Pages」**。
   * 在 **Branch** 選項中選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
4. **取得線上遊戲網址**：
   * 等待約 1 分鐘，即可透過 `https://<你的GitHub帳號>.github.io/<專案名稱>/` 讓全級學生連線遊玩！

## ⚙️ 遊戲核心機制與特色

1. **野生原野隨機遊行抓寶**：
   * 備選倉頡字母與齊全輔助字型化身為「精靈球能量球」，在畫面中平滑隨機漂浮、遊行與碰壁反彈。
   * 支援「滑鼠懸停自動停頓吸附」，專為小學生操作調校，避免追逐游標。
   * 提供「🟢 悠閒（預設）」、「🟡 敏捷」與「⏸️ 定點靜態」三段速度切換。
2. **五關挑戰循環制 (5-Stage Session)**：
   * 每輪挑戰固定為 5 關，通關後顯示成績結算面板，可重複開局。
   * 基礎得分 10 分，具備 2~5 Hit 連擊階梯加成（每關最高 20 分），5 關全中享有滿貫獎勵 +20 分。
3. **首尾同碼字無縫支援**：
   * 針對「第」（竹＋竹）、「骨」（月＋月）等題目，原野區會同時生成 2 顆獨立遊行的相同字根球，支援依序捕捉與雙擊容錯。
4. **0 至 5,000 分勳章與隨機發動技能體系**：
   * 8 大段位徽章（新手、見習、遊俠、館主、大將、宗師、大師、神域至尊）。
   * 解鎖 7 大隨機觸發技能（精準直覺、雷霆看破、聖盾防護、烈焰爆擊、時空凝滯、極限連擊、神域天罰）。

## 📡 雲端試算表 Webhook 聯網配置 (可選)

若希望學生在 GitHub 遊玩的成績自動同步寫入教師的私人 Google 試算表：
1. 打開 `index.html`，搜尋 `CONFIG`：
   ```javascript
   const CONFIG = {
     GAS_WEBHOOK_URL: "https://script.google.com/macros/s/你的Apps_Script發布網址/exec",
     GITHUB_PRIVACY_MODE: true
   };
   ```
2. 將部署好的 Google Apps Script 網頁應用程式網址填入 `GAS_WEBHOOK_URL` 即可實現背景無感自動上傳。
